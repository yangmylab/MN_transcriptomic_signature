# Audit and revision of the Paper 1 analysis — 2026-10-20

**Scope.** Every script in `R/` (47 files), every result table in `output/tables/` (106 CSVs) and
every figure file (223 PDF/JPEG across 10 directories), audited as a bioinformatics/kidney-disease
review rather than as a code-style pass. Each suspected defect was verified against the real data or
reproduced in isolation before it was recorded; two suspicions were disproved and are listed as such.

**Outcome.** 37 findings (5 high, 14 medium, 18 low/clarifying). 21 code changes applied; the
affected steps were re-run end-to-end and all six verifiers were re-run afterwards (section 7).

## 2. High-severity findings

### F01 — the panel's nested cross-validation was not nested (09a)
**Finding.** `one_fold()` reseeded with `SEED + 1000*r + k` and then drew a **fresh** `caret_folds()`
for every (repeat, fold) task. The five "folds" of one repeat therefore did not partition the
samples: mean pairwise test-set overlap 0.193 (max 0.310), and 36 of 147 samples were scored more
than once, while the output table described the run as "10 repeats × 5 folds".
**Evidence.** `Rscript /tmp/audit_folds.R` — overlap 0.193 under the old code versus exactly 0 under
a single partition per repeat.
**Fix.** `make_folds(r)` draws one partition per repeat; `one_fold(r, k, folds)` receives it.
`09a_panel_runinfo.csv` now records `fold_structure`.
**Consequence.** Selection frequencies and the consensus panel are re-derived (section 7).

### F02 — the DerSimonian–Laird fallback could never fire, and "724 genes" cannot be reproduced (04c)
**Finding.** The fallback was wired to `tryCatch(error = ...)`. metafor 5.2.1 reports Fisher-scoring
non-convergence as a **warning** and still returns a fit, so the fallback was unreachable; no counter
was written anywhere, and the log contains zero convergence messages. The manuscript's claim that
724 genes were "recovered this way" has no supporting output.
**Evidence.** `Rscript /tmp/test_reml.R` — four boundary cases, no warning, no error, τ² = 0 returned.
**Fix.** Warnings are captured with `withCallingHandlers`, the gene is refitted with DL, and
`used_dl` is stored per gene; `meta_summary.csv` gains `n_dl_fallback`. The manuscript sentence is
rewritten to report the measured count (section 7).

### F03 — I² = 0 at k = 2 is a boundary solution, not evidence of agreement (04c)
**Finding.** All primary metas are k = 2, where τ² is estimated from one degree of freedom and is
frequently pinned at 0. The manuscript read the median I² = 0 of the significant genes as "the array
and RNA-seq cohorts agreed", which the statistic cannot support.
**Evidence.** `Rscript /tmp/audit_meta.R` — every primary meta is k = 2 (one is k = 1), I² = 0 for the
significant-gene median, and the k = 1 contrast has I² undefined.
**Fix.** `meta_summary.csv` now carries `pooling`, `median_tau2_meta_deg` and `n_dl_fallback`; each
meta table carries `pooling`. The manuscript wording is corrected to describe the Q test and τ².

### F04 — deconvolution quantile-normalised the signature and the mixtures together (07f)
**Finding.** `normalizeQuantiles(cbind(sig_g, mix))` standardises 16 signature columns alongside
hundreds of mixture columns; each signature value becomes a cross-column quantile mean dominated by
the samples, flattening exactly the cell-type profiles the τ filter was introduced to preserve. The
documented symptom (two signatures disagreeing on the dominant cell type in 1,325/1,328 samples) is
consistent with this instability.
**Fix.** The two sides are quantile-normalised separately, then unit-summed.
**Consequence.** All deconvolution fractions, the Phase D trait matrix and everything downstream of
it are recomputed (section 7).

### F05 — the QC resume guard trusted 0-byte files (07b)
**Finding.** `if (file.exists(f_obj) && file.exists(f_qc))` — the exact trap recorded as P-28 after
the 2026-10-19 crash, never fixed in code.
**Fix.** Both files must also have `file.size(...) > 0`.

### F06 (added during the revision) — `00d_install_cdf.R` did not parse
**Finding.** An unbalanced parenthesis in the `WS_LIB` expression (`... [1]))), ".Rlib")` closes only
three of four calls). The script could not run; the CDF packages it installs were built via `02a`.
**Fix.** One closing parenthesis added; all 47 scripts now parse.

## 5. What was deliberately not changed

1. **REML as the primary meta estimator.** k = 2 makes REML unstable, but switching the estimator
   would replace every pooled estimate; τ², Q and the DL counter are now reported alongside, which is
   the information a reviewer needs. A Knapp–Hartung sensitivity is recommended as the next addition.
2. **voom design in 02c.** Using the disease grouping in `filterByExpr`/`voom` would change every
   RNA-seq gene set; the gain is small relative to the churn. Documented instead.
3. **snRNA mitochondrial threshold and the 6,000-cell cap** (07b/07c). Per the user's decision the
   single-cell arm was not re-run; both are stated in Methods/Limitations.
4. **02b's tie handling in quantile normalisation.** Changing it would alter the array values;
   the current implementation sorts and assigns the reference, which is the documented behaviour.
